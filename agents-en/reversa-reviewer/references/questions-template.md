## How the user responds

## How the Reviewer processes the responses

After receiving the user's notice:
1. Read the complete file
2. For each question with filled answer:
   - Update the corresponding spec
   - Reclassify the item per the answer (🔴→🟢 or 🔴→🟡)
   - Mark the question as `✅ Answered` above the Answer field
3. For questions without answer: keep as 🔴 in the final report
4. Update `confidence-report.md` with the new percentages
