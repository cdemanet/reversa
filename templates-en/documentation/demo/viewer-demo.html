SQL injection in /api/orders endpoint

CRITICAL src/api/orders.ts:47 OWASP A03:2021 

query = `SELECT * FROM orders WHERE id = ${userId}`

Direct concatenation of userId into SQL allows injection. Use parameterized queries with prepared statements.

Session cookie without HttpOnly flag

HIGH src/auth/session.ts:23

Session cookies must use the HttpOnly, Secure and SameSite=Lax flags.

Partial input validation on /signup

MEDIUM src/api/signup.ts:12

Email has a regex, password does not. Add validation for minimum length and complexity.
